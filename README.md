# 值日提醒与排班 · DutyRoster

ClassIsland 插件 —— 像管理课程表一样编排值日，并在值日时段自动提醒相关同学。

按「组别 × 值日类型」二维表组织值日安排，支持按周 / 按日 / 双周轮换，在主界面显示当前值日组，并通过 ClassIsland 原生提醒与自动化在需要的时候提醒。

## 功能

- **二维值日表编辑**：行是值日类型（扫地、拖地、擦黑板…），列是值日组（第一组…第六组），每格填人员，支持顿号、逗号、空格分隔
- **可视化轮换**：按周 / 按日 / 双周三种轮换方式，可设起始日期、跳过星期几、额外跳过节假日，并实时预览未来两周
- **手动校准当前组**：随时把「当前是第几组」一键设为指定组，之后继续自动轮换
- **主界面组件**：显示当前值日组与各项任务，可按值日类型配色
  - 可勾选只展示其中某几类值日（如只显示「扫地」和「擦黑板」）
  - 组名与类型标签的颜色可自定义，适配浅色 / 深色主题
- **原生提醒集成**：提醒提供方嵌入 ClassIsland 应用设置 → 提醒，与其他原生提醒并列；遮罩 / 正文模板可自定义，支持占位符
- **自动化**：提供「值日时段开始时」触发器，以及「值日提醒」行动（可指定组与值日类型、自定义正文和显示时长）
- **班级名单**：支持导入导出名单、随机点名；随机排值日表为预留接口
- **数据导入导出**：整份值日表可导出为 JSON，也可从 JSON 导入
- **开箱即用**：首次启动预置 6 组 × 5 类的值日表结构（含轮换规则与值日时段），人员留空由你填写

## 安装

1. 在 [Releases](https://github.com/MajHarv/ClassIsland-DutyRoster/releases) 下载最新 `.cipx`
2. ClassIsland → 应用设置 → 插件 → 右上角 `···` → 从文件安装
3. 重启 ClassIsland

## 使用

### 编辑值日表

应用设置 → **值日提醒与排班** → **值日表** 标签页：

| 操作 | 说明 |
|---|---|
| 修改表名 | 顶部表名文本框 |
| ＋ 类型 / ＋ 组 | 新增一行 / 新增一列 |
| 删除类型 / 删除组 | 删除选中的行 / 列 |
| 人员格 | 直接编辑，如「张三、李四」 |
| 保存 | 写入配置并立即刷新主界面组件 |
| 恢复示例 | 恢复预置的组别与值日类型结构，人员清空 |

### 轮换设置

**轮换** 标签页：

- **按周轮换**：每周换一组，6 组即 6 周一轮
- **按日轮换**：每天换一组，6 组即 6 天一循环
- **双周轮换**：A 周 / B 周交替，可指定每半周期的组数

「跳过规则」中勾选的星期几不排值日、也不计入轮换天数；下方可添加具体日期作为额外跳过日（节假日）。

界面顶部会显示「当前第 N 组 · 组名」，下方可手动把当前组设为任意第 N 组，用于校准轮换起点。

### 组件设置

在组件库点击「值日提醒与排班」组件：

- **展示的值日类型**：勾选要显示的类型，全部不勾选表示显示全部
- **文字颜色**：组名颜色、值日类型标签颜色，留空为默认（组名白色、标签浅灰）

### 提醒

两个层次：

1. **插件自己的开关**：值日提醒与排班 → 其他 → 发送值日提醒
2. **ClassIsland 原生提醒**：应用设置 → 提醒 → **值日生提醒**，可配置提前秒数、遮罩文本、正文模板、是否朗读

正文模板支持占位符：

| 占位符 | 含义 |
|---|---|
| `{group}` | 组名，如「第一组」 |
| `{types}` | 单行值日项，如「🧹 扫地：张三  \|  🖊 擦黑板：李四」 |
| `{typesLines}` | 多行值日项，每类一行 |
| `{type}` | 首个值日类型名 |
| `{name}` | 首个值日类型的同学姓名 |
| `{schedule}` | 时段名 |
| `{date}` | 日期 |
| `{table}` | 表名 |

例如正文填 `请{name}同学{type}`，配合自动化行动只选「擦黑板」时，就会提醒「请张三同学擦黑板」。

### 自动化

- **触发器**：自动化 → 添加触发器 → **值日时段开始时**，可指定监听哪个时段、提前 / 延后多少秒、是否只在当天有值日安排时触发
- **行动**：自动化 → 添加行动 → **值日提醒**，可指定提醒当前组或某一组、指定值日类型、自定义遮罩 / 正文模板、标题与正文的显示时长、是否朗读

### 班级名单

**班级名单** 标签页：每行一位同学，可写「01 张三」。支持导入 / 导出 `.txt`，以及随机点名。

「随机排值日表」目前是**预留接口**，接口签名为后续实现预留了组数、值日类型与人数要求。

## 数据文件

配置保存在插件配置目录下的 `duty_roster.json`。设置页「其他 → 数据」可查看完整路径，也可在此处导出 / 导入。

### 目录结构

```
.
├── Models/
│   ├── DutyType.cs            值日类型（表格行）
│   ├── DutyGroup.cs           值日组（表格列）与单元格
│   ├── DutySchedule.cs        值日时段
│   ├── Student.cs             班级名单条目
│   ├── DutyConfig.cs          根配置
│   ├── RotationSettings.cs    轮换参数
│   ├── DutyNotificationSettings.cs
│   └── Rotation/
│       ├── IRotationPreset.cs        轮换预设接口（扩展点）
│       ├── WeeklyRotationPreset.cs   按周
│       ├── DailyRotationPreset.cs    按日
│       ├── BiweeklyRotationPreset.cs 双周
│       └── RotationPresetRegistry.cs 注册表
├── Services/
│   ├── ConfigService.cs       配置读写
│   ├── DutyFormatter.cs       显示 / 提醒文案（含占位符）
│   ├── DefaultDutyData.cs     预置值日表结构（人员留空）
│   └── ClassRosterService.cs  班级名单与随机点名（随机排班预留）
├── Components/                主界面组件与组件设置
├── Notifications/             提醒提供方与设置控件
├── Automation/                自动化触发器 / 行动与设置控件
└── Settings/                  插件设置页
```

### 扩展轮换方式

实现 `IRotationPreset`，然后在 `RotationPresetRegistry` 中登记即可。组件、提醒提供方与设置页会自动支持，无需改动其他代码。

### 扩展随机排班

实现 `ClassRosterService.GenerateRandomRoster`，返回 `RandomRosterResult`。配置结构与 UI 无需变动。

## 构建

```bash
dotnet build -c Release
```

需要 .NET 8 SDK 与 `ClassIsland.PluginSdk` 2.0.0.x（NuGet）。构建后插件包输出在 `cipx/DutyRoster.cipx`，校验和在同目录 `checksums.md`。
